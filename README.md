# TP-devops

## Description

Ce projet est réalisé dans le cadre du module DevOps
à l'Université Abderrahmane Mira de Béjaïa.

Il permet de pratiquer les commandes Git, la gestion des branches,
la résolution des conflits et la collaboration via GitHub.

## Technologies

- Python
- Git
- GitHub
